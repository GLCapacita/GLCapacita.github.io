# GL Capacita

Plataforma de capacitación de GL Robótica Submarina SpA (curso art. 16 D.S. 44, IRL, Matriz IPER, planes de emergencia, EPP, accidentes y procedimientos por cargo).

- Trabajadores: `index.html`
- Panel de administración: `admin.html`
- Verificación de certificados: `verificar.html`

Los datos de los trabajadores no se guardan en este repositorio: quedan en Google Drive (planilla "GL Capacita - Registros" y carpeta "GL Capacita"), a través del servidor Google Apps Script configurado en `js/config.js`.
