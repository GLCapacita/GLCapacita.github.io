# PyV Capacita

Plataforma de capacitación asincrónica de Servicios Acuícolas PyV Rain Vega SpA (curso art. 16 D.S. 44 según Res. Ex. 1117/2026, IRL, Matriz IPER, PRRD, EPP, accidentes y PTS por cargo).

- Trabajadores: `index.html`
- Panel de administración: `admin.html`
- Verificación de certificados: `verificar.html`

Los datos de los trabajadores no se guardan en este repositorio: quedan en el Google Drive de PyV (servidor Google Apps Script configurado en `js/config.js`).
